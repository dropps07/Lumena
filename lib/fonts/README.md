# Custom Fonts

This directory should contain the custom fonts from Indian Type Foundry:

1. **Chillax-Variable.woff2** - For headings
2. **ClashDisplay-Variable.woff2** - For subheadings

## How to add the fonts:

1. Download the fonts from Indian Type Foundry
2. Convert them to .woff2 format if needed
3. Place them in this directory
4. The fonts will be automatically loaded by the application

## Font Usage:

- **Chillax**: Used for main headings (font-chillax class)
- **Clash Display**: Used for subheadings (font-clash-display class)

## Note:

If you don't have the fonts yet, the application will fall back to system fonts.
